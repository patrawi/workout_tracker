Uncertainty propagation: quick reference

Measurement model: Y = f(X₁, …, Xₙ). For this project, Y is a nutrient result and the X values include portion mass, recipe composition, added oil, and consumed fraction.

V1: deterministic scenarios

  • Calculate a central estimate, then minimize and maximize each nutrient subject to mass-balance and evidence constraints.
  • Use when priors are uncalibrated and the output is a Plausible Nutrition Range.
  • Never call an AI API inside the scenario calculation.
N = Σ(mᵢ × nutrient_densityᵢ / 100)
subject to:
  Σmᵢ = component_mass
  mᵢ ≥ 0
  known ingredient bounds are respected

Future: Monte Carlo propagation

  • Sample uncertain inputs locally, then run the same deterministic function repeatedly.
  • Use when input distributions and dependencies are defensible and output coverage will be validated.
  • Use a reproducible seed and cache by input, reference-data, and estimator versions.

Decision rule

Use constrained interval calculation while the model is mostly linear and priors are heuristic. Monte Carlo becomes valuable for defensible nonlinear, skewed, or correlated uncertainty; it cannot rescue incorrect input assumptions, and more samples do not create new evidence.
