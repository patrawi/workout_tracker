# Split minimum input by portion mode

Estimated mode requires only the user-provided menu name and a before image, with the VLM proposing Portion Components and approximate weights for review. Measured mode requires the menu name plus at least one scale-measured component weight, with the before image optional because the calculation already runs on real measured masses. We chose per-mode minimums over a uniform photo requirement so measured logging, which is already trustworthy, avoids capture friction, while estimated logging keeps the photo evidence its calculation depends on.
