# Selectable vision provider — Gemini alongside DeepSeek

`VLM_PROVIDER` ("deepseek" default | "gemini") selects which implementation of the ADR 0025 provider-neutral vision adapter backs `/api/meal-observations/interpret`; the Gemini path calls `gemini-3.8-flash` (override via `GEMINI_VISION_MODEL`) over the v1beta `generateContent` REST API with `systemInstruction` + `responseMimeType: application/json`, sharing the contract, prompt, and anti-anchoring parsing via `vlm/contract.ts`. We added the second provider because the vision role is now benchmarked independently of the text parser — a 2026-10-06 live smoke test showed Gemini 3.8 Flash anchoring its weight proposals on the ADR 0028 user-note constraints exactly (rice 200 g, oil level low) — and the neutral adapter reduced the swap to a wiring change; DeepSeek stays the default and remains maintained, so ADR 0010's same-model ablation pairing is still available when attribution experiments need it.
