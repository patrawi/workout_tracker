# Keep VLM output as confirmable proposals and hide low-confidence fields

The VLM returns a structured proposal: one dish-name suggestion, per-component low/central/high before weights, a per-component consumed fraction when an after image exists, coarse latent-factor hints, and a confidence level; it never performs nutrition arithmetic and never ranks reference candidates. Fields with low confidence are hidden rather than displayed so the user fills them manually without anchoring, and unusable output such as no food or an unreadable image falls back to manual entry; logging is never blocked by a VLM failure. We chose hiding over flagged display because showing weak guesses anchors the user's corrections, and chose non-blocking fallbacks so a failed model call can never prevent an honest meal record.
