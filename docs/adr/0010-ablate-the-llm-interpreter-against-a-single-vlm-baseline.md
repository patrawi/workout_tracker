# Ablate the LLM interpreter against a single-VLM baseline

The V1 production baseline is VLM structured evidence → PostgreSQL/ThaiFCD retrieval → deterministic Bun calculation → user review. Evaluate an optional LLM interpreter as a paired ablation using the same cached VLM outputs, reference snapshot, calculation version, and evaluation meals, so accuracy, correction burden, latency, and cost differences can be attributed to the interpreter alone; it enters the main pipeline only if predefined acceptance criteria are met. The interpreter may re-rank candidates, translate visual evidence into bounded latent factors, and propose coarse Portion Components, but it may not alter measured facts, perform nutrition arithmetic, or invent unsupported ingredients. During evaluation it runs only in shadow/offline mode: its output is stored for comparison and cannot change a displayed estimate or saved nutrition log. Routine user confirmation produces Reviewed Meal Labels for correction-burden metrics, while a smaller independently labeled subset provides Gold Meal Labels for less-biased comparison; neither is treated as hidden nutrient ground truth.
